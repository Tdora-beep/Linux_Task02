# Command Explanation

The following commands are used because they correspond to the uploaded task.

| Command | Purpose |
|---|---|
| `whoami` | Confirms the current logged-in user. |
| `useradd` | Creates the new Linux user required by the task. |
| `passwd` | Sets the user's password. |
| `usermod -aG sudo` | Adds the user to the sudo group when required. |
| `su` | Switches to another user account. |
| `mkdir` | Creates directories. |
| `cd` | Changes the current directory. |
| `echo` | Writes the required text into a file. |
| `ls -la` | Lists files, including hidden files, with detailed information. |
| `nano` | Opens a text file for editing. |
| `cp` | Copies files/directories. |
| `mv` | Moves or renames files. |
| `chmod` | Changes file permissions. |
| `rm` | Deletes a file. |
| `tree` | Displays the project directory structure. |
| `history` | Lists previously entered shell commands. |
| `>` | Redirects command output into a file. |
